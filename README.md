# gurtos-droid-demo

A throwaway repo for the GurtOS Factory demo. A GurtOS box watches it for issues labelled `droid`. For each one,
Droid plans the fix (the box owner approves the plan from the portal or phone), a coder droid makes the change, a
reviewer droid checks the diff, and the box opens a pull request with its own token. Droid never holds the token.

Run the tests with `npm test`.
